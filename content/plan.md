# Контент-план бабы Зои (пересобран 27.09)

## Что делает ролик досматриваемым
- **Первый кадр — самый «вкусный»**: хруст корки, мёд тянется, соты крупно. Никаких вступлений.
- **Первая фраза — разрыв шаблона**: «Этой закваске 50 лет», «Мёд в кипяток — зря», «Внук назвал это суперфудом».
- **Одна мысль на ролик**, 20–25 секунд, 4 сцены. Короче — выше досмотр.
- **Бытовая ситуация зрителя**: объелся на празднике, покупает дорогой «суперфуд», кладёт мёд в чай.
- **Тёплая бабушкина подача**: юмор, дед Коля, внук — эмоция вместо лекции.
- **Подпись длинная**: история + рецепт по шагам (ради него сохраняют) + вопрос в комментарии.
- Без «3 правила / 5 советов», без слов «лечит», без названий болезней.
