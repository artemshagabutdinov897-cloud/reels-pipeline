# Сюда загружать сгенерированное в Братухе

Для каждого ролика — своя папка с его id, например `inbox/01-kapusta/`:

- `scene_1.mp4`, `scene_2.mp4`, … — клипы из Seedance по порядку сцен;
- `voice.mp3` (или .wav/.m4a) — озвучка.

Как загрузить на GitHub: откройте эту папку в ветке `main`
→ **Add file** → **Upload files** → в поле имени папки допишите `01-kapusta/` → перетащите файлы → **Commit changes**.

Промпты для каждого ролика — в `content/prompts/<id>.md`.
